# Pitch Luna — If Vocal

歌の音程練習ソフト（Windows / Python）。

曲（MP3 など）を読み込むと、AI が歌声と伴奏を分けて「お手本の音程」を水色のバーで表示します。
マイクで歌うと自分の声の高さがオレンジのバーでリアルタイムに流れ、お手本と合っているとバーが光ります。

## 主な機能
- AI による歌声と伴奏の分離（Demucs）・お手本の音程の解析（CREPE など）・キー（調）と小節の解析
- ドレミ表示の楽譜、自分の声のリアルタイム表示と一致率
- A-B ループ再生、再生速度の変更（0.7〜1.0倍・音程はそのまま）、キー変更（±6半音）
- 歌唱の録音とテイク再生、お手本バーの簡易エディタ、MIDI のお手本
- 自分の声のモニター（雑音カット・ハウリング防止）、マイク / スピーカーの選択
- ソフトの中からのアップデート（ヘルプ → アップデートを確認）

## 起動
```
cd C:\Users\shell\Downloads\singing
python singing_trainer.py
```
はじめての準備は `setup.bat`。使い方は `取扱説明書.txt` をご覧ください。

## アップデートのしくみ
`version.json` に最新の版番号・変更点・各ファイルの確認用の値（SHA-256）が書いてあります。
ソフトはこれと自分のファイルを比べ、変わったファイルだけをダウンロードして入れ替えます（`updater.py`）。
新しい版を作るときは `python make_release.py 版番号 "変更点" ...` で `version.json` を作り直します。

フォントは Noto Sans JP（SIL Open Font License、`fonts/LICENSE-NotoSansJP.txt`）を使っています。
