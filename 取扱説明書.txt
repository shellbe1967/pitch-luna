================================================================
  Pitch Luna — If Vocal　取扱説明書
  （歌の音程練習ソフト）
================================================================

  曲（MP3 など）を読み込むと、AI が歌声と伴奏を分けて、
  「お手本の音程」を水色のバーで表示します。
  マイクで歌うと、自分の声の高さがオレンジのバーでリアルタイムに流れ、
  お手本と合っているとバーが光ります。

 1. 必要なもの
================================================================

  ・Windows 10 / 11 のパソコン
  ・Python 3.10 以上（3.12 で動作確認）
  ・マイク（パソコン内蔵でも可。USB マイクやヘッドセットがおすすめ）
  ・ヘッドホン / イヤホン（自分の声を聞くときは必須。ハウリング防止）
  ・NVIDIA のグラフィックボード（あると解析が速い。無くても CPU で動きます）

  フォルダ： C:\Users\shell\Downloads\singing


================================================================
 2. はじめての準備（インストール）
================================================================

  ■ ビルド版（ZIP）を使う場合 … 準備はいりません（おすすめ）
    1) ZIP ファイルを右クリック →「すべて展開」で、好きな場所に展開します
       （例：C:\Users\shell\PitchLuna）。
       ※ デスクトップや「ダウンロード」でも動きますが、Program Files の中は避けてください
         （設定や解析結果を書き込めないため）。
    2) 展開したフォルダの「PitchLuna.exe」をダブルクリックすると起動します。
       Python やライブラリのインストールは不要です（AI 解析の部品もグラボ対応で入っています）。
    3) 初めて起動するとき、Windows の「PC が保護されました」という画面が出ることがあります。
       「詳細情報」→「実行」を押してください（署名のない個人のソフトのため）。
    4) 初めて曲を解析するときは、AI のモデル（約300MB）をダウンロードするため
       インターネット接続が必要です（2回目からは不要）。
    ・デスクトップにショートカットを作るときは、PitchLuna.exe を右クリック →
      「その他のオプションを表示」→「送る」→「デスクトップ（ショートカットを作成）」。
    ・ZIP の中のフォルダ構成はそのままにしてください（_internal フォルダが必要です）。

  ■ Python で動かす場合（これまでの方法）

  1) フォルダの中の「setup.bat」をダブルクリックします。
  2) 必要なライブラリ（pygame・sounddevice・numpy・scipy・librosa・
     demucs・torch など）を自動でインストールし、動作確認をします。
     ・NVIDIA のグラボがあれば、グラボ用の torch を入れます。
     ・最後に「OK ○○ / 注意 ○○」のまとめが表示されます。
     ・結果は setup_log.txt にも保存されます。
  3) 「NG」があったときは、表示された内容を確認してください。

  ※ 初めて曲を解析するときは、AI のモデルをダウンロードするため
    インターネット接続が必要です（2回目からは不要）。

 3. 起動と終了
================================================================

  ■ 起動（ビルド版）
    PitchLuna.exe をダブルクリックします。

  ■ 起動（Python で動かす場合）
    コマンドプロンプトで次のように入力します。

      cd C:\Users\shell\Downloads\singing
      python singing_trainer.py

    ・起動すると「空の楽譜」の画面が開きます（曲は後から選びます）。
    ・起動直後は再生しません。Space または「▶ 再生」で開始します。
    ・自分の声の出力（モニター）は、起動時はいつも OFF です。

  ■ 終了
    ・ウィンドウ右上の × 、または「ファイル → 終了」。
    ・楽譜の画面では Esc を押しても終了しません（誤操作防止）。

  ■ ウィンドウ
    ・ウィンドウの大きさは自由に変えられます（最大化・最小化も可）。
    ・F11 で全画面表示 / 元に戻す。

 5. 曲を選ぶ・解析する
================================================================

  ■ 曲の選び方
    ・「ファイル → 曲の一覧から選ぶ」(Ctrl+L)
        フォルダの中の曲が一覧で表示されます。ダブルクリック（または Enter）で開きます。
        文字を入力すると曲名で絞り込めます。並べ替えもできます。
        「← 楽譜に戻る」または Esc で楽譜に戻ります。
    ・「ファイル → フォルダを開く…」(Ctrl+F)　曲の入ったフォルダを選びます。
    ・「ファイル → 曲ファイルを直接開く…」(Ctrl+O)

  ■ 使える曲のファイル
    MP3 / WAV / M4A / FLAC / OGG / AAC / WMA

  ■ 解析（初めて開く曲だけ）
    1) AI（Demucs htdemucs_ft）で「歌声」と「伴奏」に分けます。
    2) 歌声から音程を調べ、お手本のバーを作ります（CREPE など）。
    3) 曲のキー（調）を調べます。
    4) 伴奏から拍と小節を調べます。

    ・グラボ（GPU）があれば自動で使います。目安：5分の曲で数十秒〜数分。
      CPU だけの場合はもっと時間がかかります。
    ・解析中に Esc で中止して楽譜に戻れます。
    ・結果は cache フォルダに保存されるので、2回目からはすぐに開きます。
    ・一覧の画面の「設定」メニューで、グラボを使うかどうかを切り替えられます。

  ■ お手本が出ない曲
    伴奏だけの曲（カラオケ音源）など、歌声が見つからない曲では案内が出ます。
    同じ曲のメロディの MIDI があればお手本にできます（11章）。

 6. 再生と移動
================================================================

  ・再生 / 一時停止 …………… Space、または「▶ 再生」ボタン
  ・巻き戻し / スキップ ……… ← / →（スキップ間隔の秒数だけ）
  ・スキップ間隔 ……………… ↑ / ↓ で 1秒ずつ（下のボタンの − ＋ でも）
                              初期値は 5秒。画面上部に表示されます。
  ・最初に戻る ………………… Home、または |◀ ボタン
  ・好きな位置へ ……………… 上の進行バーをクリック / ドラッグ
  ・楽譜をクリック ………… クリックした時刻へ移動
  ・楽譜を左右にドラッグ …… 前後へ移動（離した位置から再開）
  ・ホイール ………………… 1秒ずつ前後へ移動

  ・ボーカル（お手本の歌声）を鳴らす / 消す …… V キー、または「ボーカル ON/OFF」
    OFF にすると伴奏だけになり、カラオケのように練習できます。
  ・ボーカルの音量 ……………… 「ボーカル ON/OFF」の横の「− ％ ＋」で 1%ずつ
                              （押しっぱなしで連続・% の上でホイールでも）
                              0〜200%。伴奏の音量はそのままで、お手本の歌声だけ大きく / 小さくなります。
                              設定は保存され、次に起動しても同じ音量です。
  ・曲の音量 ………………… − / + キーで 10%ずつ、下の「曲 − ／ ＋」で 1%ずつ


================================================================
 7. 歌って練習する（自分の声のバー・採点）
================================================================

  ・マイクで歌うと、自分の声の高さがオレンジのバーで流れます。
  ・お手本との差が 50セント（半音の半分）以内だと、お手本のバーが光り、
    合っていた部分は明るいまま残ります。
  ・右上の「あなた」に今の音名と、お手本とのずれ（セント）が出ます。
      緑＝合っている / 黄＝少しずれ / 赤＝大きくずれ
  ・左の音名の列でも、今歌っている音がオレンジで強調されます。
  ・自分の声が画面の外（高すぎ / 低すぎ）のときは、矢印で方向を示します。
  ・一致率（採点）は上の帯に表示されます。R キーでリセット。
  ・P キーで、お手本の細い音程線（元の歌い方の揺れ）を表示 / 非表示。


================================================================
 8. 自分の声をヘッドホンから出す（モニター）
================================================================

  ・O キー、または下の「自分の声 ON/OFF」ボタンで切り替えます。
  ・起動時はいつも OFF です。必ずヘッドホンをつけてから ON にしてください。

  ■ 音量
    ・下の「音量 − ／ ＋」で 1%ずつ（押しっぱなしで連続）。
      間の % 表示の上でホイールを回しても変えられます。
    ・9 / 0 キーで 5%ずつ。
    ・「音声 → 音量の調整（スライダー）…」でスライダーのパネルを開けます。
    ・0〜300% まで。

  ■ 自動で聞きやすい大きさに（初期設定：ON）
    マイクの声が小さいときに、自動で聞きやすい大きさ（最大 約16倍）まで持ち上げます。
    音量パネルの「自動」ボタン、または「音声」メニューで ON / OFF。

  ■ ハウリング防止
    ON の間にハウリング（ピーッ・キーン）が続くと、自動で OFF にして知らせます。
    パソコン内蔵のマイクとスピーカーの組み合わせは、ハウリングしやすいので注意。

  ■ 遅れを小さくする
    ・「音声 → 方式」で、音の出し入れの方式を選べます。
      自動（おすすめ）/ WASAPI / WDM-KS / DirectSound / MME
    ・「自分の声の遅れ」の目安がメニューと音量パネルに表示されます。
    ・Bluetooth（ワイヤレス）のヘッドホンは遅れが大きくなります。有線がおすすめです。

 9. 雑音カット
================================================================

  周りの雑音を自動で測り、歌声のときだけ声を通します。
  雑音だけのときは音を小さくし、声の高さのバーも出しません。

  ■ 開き方
    「音声 → 雑音カットの調整…」、N キー、または音量パネルの「細かく調整…」。

  ■ 強さ（初期設定：中）
    OFF / 弱 / 中 / 強 から選びます。

  ■ 細かい調整（値を変えると「カスタム」になります）
    ・声とみなす大きさ（雑音 +0〜30dB）
        大きいほど雑音を通しにくい。大きすぎると小さな声も切れます。
    ・雑音を下げる量（0〜−60dB）
        雑音だけのときに、どれだけ小さくするか。
    ・余韻（0.05〜0.8秒）
        声が止まってから絞り始めるまでの時間。語尾が切れるときは長く。
    ・低い音を切る（OFF〜250Hz）
        エアコン・振動・電源の「ブーン」という低い音を切ります。
    ・今の雑音を測る（2秒 静かに）
        ボタンを押して2秒静かにすると、その間の音を雑音として測り直します。

  ■ メーターの見かた
    ・バー：今のマイクの大きさ（緑＝声として通している / 灰色＝雑音として小さく）
    ・白い線：自動で測った周りの雑音の大きさ
    ・黄色い線：これより大きい音を「声」とみなす境目

  ■ 調整のコツ
    歌わずに黙っているときに、バーが黄色い線より左（灰色）になればOK。
    まだ雑音が聞こえる → 「声とみなす大きさ」を上げる
    歌声が途切れる　　 → 「声とみなす大きさ」を下げる / 「余韻」を長く

 10. マイク・スピーカーの選択（デバイス）
================================================================

  メニューバーの「デバイス」から選びます。

  ・マイク（入力）
      「Windows の既定のマイク」か、つながっているマイクを選びます。
  ・スピーカー / ヘッドホン（出力）
      選んだ機器から、曲と自分の声の両方が出ます。
      曲の再生中に変えても、同じ位置から続けて鳴ります。
  ・テスト音を鳴らす
      選んだスピーカーから短い音を鳴らして確認できます。

  ・選んだ機器は保存され、次に起動したときも同じ機器を使います。
  ・選んだ機器が外れているときは、Windows の既定の機器で開いて知らせます。
  ・機器を後からつないだときは、もう一度「デバイス」メニューを開くと一覧が新しくなります。

 11. お手本の切り替え（MIDI・オクターブ）
================================================================

  ■ オクターブ
    お手本の高さが自分の声域と合わないときに使います（男女で歌うときなど）。
    [ / ] キー、または下の「オクターブ ↓ / ↑」で ±1オクターブ（最大 ±2）。
    「お手本 → 原曲の高さに戻す」で元に戻ります。

  ■ MIDI をお手本にする
    ・曲と同じ名前の MIDI ファイル（.mid / .midi / .kar）を同じフォルダに置くと、
      開いたときに自動で使います。
        例： 曲名.mp3 と 曲名.mid
    ・「ファイル → この曲に MIDI を合わせる…」(Ctrl+M) で選ぶこともできます。
    ・MIDI のメロディのパートとタイミングは、歌声に合わせて自動で調整します。
    ・タイミングがずれているときは , / . キーで 0.05秒ずつ調整（保存されます）。
    ・M キーで「MIDI」と「歌声から解析したお手本」を切り替えられます。

 12. 小節線（拍の解析）
================================================================

  曲を開くと、伴奏から テンポ・拍・小節の頭（1拍目）・拍子 を自動で調べ、
  タテ線を小節ごとに引きます（小節の区切り＝実線、拍＝点線）。
  上の帯に「小節（今の小節・拍）」と「テンポ（♩=○○ ○拍子）」が表示されます。
  リズムの無い曲では、秒ごとの線になります。

  ■ 小節線がずれているときの直し方（直した内容は曲ごとに保存）
    ・楽譜の上の目盛りをダブルクリック …… その拍を小節の頭（1拍目）にする
    ・Shift を押しながら目盛りをドラッグ …… 小節線全体を左右に動かす
    ・目盛りの上で Shift+ホイール ………… テンポを 0.5 ずつ変える
    ・楽譜を右クリック ……………………… その場所で小節・拍子・テンポのメニュー
    ・「小節」メニュー
        今の位置を小節の頭にする / 1拍 前へ・後ろへ / 2・3・4・6拍子 /
        テンポを上げる・下げる / 小節線を少し動かす / 解析結果に戻す


================================================================
 13. グリッド（縦・横の拡大縮小）
================================================================

  ■ 音階を中央に（初期設定：ON）
    これから歌う音が、画面の上下の真ん中に来るように自動で動きます。
    C キーで ON / OFF。

  ■ 横（時間方向）の拡大・縮小
    ・楽譜の上の目盛りを左右にドラッグ（右＝拡大 / 左＝縮小）
    ・目盛りの上でホイール、または楽譜のどこでも Ctrl+ホイール
    ・「画面に 1・2・4・8・16 小節」を選ぶ（グリッドメニュー / パネル / 右クリック）

  ■ 縦（音の高さ方向）の拡大・縮小
    ・左の音名の列を上下にドラッグ（上＝拡大 / 下＝縮小）
    ・左の音名の上でホイール、または楽譜のどこでも Shift+ホイール
    ・「オクターブ 1・1.5・2・3・4」を選ぶ（パネル）

  ■ 上下に動かす（手動）
    ・Shift を押しながら左の音名をドラッグ / Shift+ホイール（音名の上）
    ・PageUp / PageDown
    ※ 手動で動かすと「音階を中央に」は OFF になります。

  ■ グリッドの調整パネル（G キー、または「グリッド → グリッドの調整パネル…」）
    縦・横のスライダー、オクターブ数、小節の数、線の濃さ（0〜200%）、
    タテ線（小節 / 0.5・1・2・5秒）、拍子、1拍目、テンポ、
    音階を中央に・拍の点線・♯の段の点線 の ON/OFF、元に戻す。

  ・表示の設定は保存され、次に起動しても同じ見た目になります。


================================================================
 14. A-B ループ再生
================================================================

  好きな区間（A 点〜B 点）を何度もくり返して練習できます。
  区間は水色でハイライト表示され、上の進行バーにも金色で表示されます。

  ■ 区間の決め方
    ・A キー …… 今の位置を A 点（始め）に
    ・B キー …… 今の位置を B 点（終わり）に → 自動でループ ON
    ・楽譜を Shift を押しながら左右にドラッグ …… その範囲をループ
      （小節線があるときは、拍の位置にそろいます）
    ・楽譜を右クリック → 「ここを A 点に」「ここを B 点に」
      「この小節をループ」「この2小節をループ」
    ・「練習 → 今の小節をループ」
    ・下の2段目の「A 点」「B 点」ボタン

  ■ 調整・操作
    ・楽譜の上端の「A」「B」の旗を左右にドラッグすると、位置を直せます
      （Shift を押しながらだと、拍にそろえずに細かく動かせます）。
    ・L キー（または「ループ ON/OFF」）でループの ON / OFF。
    ・「解除」でA点・B点を消します。
    ・ループ中は Home キーで A 点に戻ります。
    ・楽譜の右上に「ループ ○回目」と表示されます。
    ・A-B は曲ごとに保存され、次に開いたときも同じ区間です。


================================================================
 15. 再生速度の変更（音程はそのまま）
================================================================

  音程を変えずに、0.70倍〜1.00倍（0.05倍きざみ）で遅く再生できます。
  楽譜のスクロール・お手本バー・自分の声のバー・小節線もすべて同じ速さで動きます。

  ・Shift+← / Shift+→ …… 0.05倍ずつ遅く / 速く
  ・下の2段目の「速度 − ／ ＋」（数字の上でホイールでも）
  ・「練習」メニューの「再生速度 1.00 / 0.90 / 0.80 / 0.70倍」

  ・初めての速度にするときは、音を作り直すため数秒かかります
    （上の帯に「準備中 ○○%」と表示。その間は今の速さのまま再生を続けます）。
  ・一度作った速度は、すぐに切り替わります。
  ・速度は曲ごとに保存されます。


================================================================
 16. キーの変更（移調）
================================================================

  伴奏・ボーカル（お手本の歌声）・お手本バーを、まとめて半音単位（-6〜+6）で
  上げ下げできます。自分の声域に合わせて練習するときに使います。

  ・Shift+↑ / Shift+↓ …… 半音上げる / 下げる
  ・下の2段目の「キー ♭ ／ ♯」（数字の上でホイールでも）
  ・「練習 → キー：半音上げる / 下げる」「速度・キーを元に戻す」

  ・画面上部のキーの表示（例：ミ・マイナー → ファ♯・マイナー）と音階の行も変わります。
  ・準備に数秒かかるのは速度と同じです。キーは曲ごとに保存されます。
  ・オクターブの切り替え（[ / ]）はお手本バーだけを動かしますが、
    キーの変更は曲の音も一緒に変わります。


================================================================
 17. 録音とテイク再生
================================================================

  歌っている声を裏で録音し、あとで伴奏と合わせて聴き直せます。

  ■ 録音
    ・T キー（または「● 録音」ボタン）で録音モード ON。
    ・録音モードの間は、再生している間ずっと録音します。
      一時停止・移動・ループで戻るたびに、1つの「テイク」になります。
      （A-B ループと組み合わせると、1回歌うごとに1テイクになります）
    ・上の帯に「録音 ● 0:12」と表示されます。もう一度 T で OFF。

  ■ 聴き直す（テイク再生）
    ・Y キー（または「▶ テイク」）で、最後のテイクを再生します。
      録音した位置に自動で頭出しして、伴奏と自分の声を一緒に鳴らします
      （お手本の歌声はその間だけ消します）。
    ・録音した声の高さがオレンジのバーで表示され、お手本との一致率も分かります。
    ・Space、または「■ 停止」で止めます。
    ・「一覧」ボタン（または「練習 → テイクの一覧…」）で、前のテイクを選んで再生できます。
      一致率・録音した位置・時刻が表示されます（最近の12テイクまで）。

  ■ そのほか
    ・テイクを WAV で保存：一覧の「最後のテイクを WAV で保存」
      → 曲の解析フォルダ（cache\曲名_xxxx\takes）に保存されます。
    ・声と伴奏がずれて聞こえるとき：一覧の「ずれ補正：早める / 遅らせる」
      （0.02秒ずつ。保存されます）。
    ・速度を変えて録ったテイクも、今の速度に合わせて再生します。
    ・テイクはソフトを閉じると消えます。残したいものは WAV で保存してください。


================================================================
 18. お手本バーの手動補正（簡易エディタ）
================================================================

  AI の解析で間違えたお手本バーを、自分で直して保存できます。

  ■ 編集モード
    E キー（または下の「編集」ボタン / 「お手本 → お手本を編集する」）で ON / OFF。
    楽譜の下に黄色の帯が出ます。再生は止まります（Space で再生もできます）。

  ■ 選ぶ
    ・バーをクリック …… そのバーを選ぶ（白い枠）
    ・Shift+クリック …… 選ぶバーを増やす / 外す
    ・何もない所からドラッグ …… 四角で囲んだバーをまとめて選ぶ
    ・Ctrl+A …… 画面に見えているバーをすべて選ぶ
    ・Esc …… 選択を外す（もう一度 Esc で編集モードを終わる）

  ■ 直す
    ・Delete（または Backspace）…… 選んだバーを削除
    ・↑ / ↓ …… 半音上げる / 下げる
    ・Shift+↑ / Shift+↓（PageUp / PageDown）…… 1オクターブ上げる / 下げる
    ・選んだバーを上下にドラッグ …… 音程を変える
    ・右クリック …… 削除・上げる・下げる のメニュー
    ・Ctrl+Z …… 元に戻す　　Ctrl+Y …… やり直す

  ■ 保存（別名保存）
    ・Ctrl+Shift+S、または「お手本 → 編集版を別名で保存…」で名前をつけて保存。
    ・Ctrl+S で上書き保存。
    ・保存すると、お手本が「編集版（名前）」になります。
    ・保存した編集版は「お手本」メニューの一覧から選べます。
    ・最後に使った編集版は、次にその曲を開いたときも自動で使います。
    ・M キーで、元のお手本（歌声から解析 / MIDI）と切り替えられます。
    ・元の解析結果は書き換えないので、いつでも元に戻せます。

 23. 困ったときは
================================================================

  Q. 起動しない / エラーが出る
     → setup.bat をもう一度実行してください。
       それでも出るときは、表示されたエラーの文字をそのまま控えてください。

  Q. 声のバーが出ない / 反応しない
     → 「デバイス」メニューで正しいマイクを選んでいるか確認。
     → Windows の「設定 → システム → サウンド → 入力」でマイクの音量を 80〜100 に。
     → 雑音カットが強すぎる場合は「弱」や「OFF」にしてみる。
     → python test_mic_pitch.py でマイクの反応を確認できます。

  Q. 自分の声が小さい
     → 「自動で聞きやすい大きさに」を ON に。音量を 100〜300% に上げる。
     → Windows のマイク音量を上げる。

  Q. 周りの雑音が聞こえる
     → 雑音カットを「中」や「強」に。「今の雑音を測る」を試す。（9章）

  Q. 自分の声が遅れて聞こえる
     → 「音声 → 方式」を「自動」または「WASAPI」に。有線のヘッドホンを使う。

  Q. ハウリングする（ピーッ・キーン）
     → ヘッドホンを使ってください。自分の声の音量を下げてください。
       ハウリングが続くと自動で OFF になります。

  Q. 曲の音が出ない / 別のスピーカーから出る
     → 「デバイス」メニューでスピーカーを選び、「テスト音を鳴らす」で確認。

  Q. お手本のバーに空白が多い / ずれている
     → 歌声が小さい曲・コーラスが多い曲は苦手です。MIDI があれば MIDI を使う。
     → 音程が1オクターブずれて見えるときは [ / ] で調整。

  Q. 小節線がずれている
     → 目盛りのダブルクリックや右クリックのメニューで直せます。（12章）

  Q. 解析が遅い
     → グラボ（NVIDIA）がある場合は「設定 → 解析にグラボを使う」が ON か確認
       （曲の一覧の画面のメニュー）。

  Q. 速度やキーを変えても、すぐに変わらない
     → 初めての組み合わせは音を作り直すため数秒かかります（上の帯に「準備中 ○○%」）。

  Q. テイクを聴くと、声と伴奏がずれている
     → テイクの一覧の「ずれ補正」で 0.02秒ずつ合わせてください（保存されます）。

  Q. お手本の編集を間違えた
     → Ctrl+Z で元に戻せます。保存した編集版をやめたいときは、M キーで
       元のお手本に切り替えるか、cache\曲名_xxxx\edits の中のファイルを削除します。

  Q. 歌詞のふりがな（読み）が違う
     → その文字をダブルクリックして、正しい読みを入力してください。（26章）

  Q. 歌詞の文字がバーとずれている
     → 文字を左右にドラッグするか、右クリック →「ここから行の終わりまでを 1つ前 / 後ろのバーへ」。
       全体にずれるときは「歌詞 → 行の歌い出しを記録する」を試してください。（26章）

  Q. 画面が見づらい
     → グリッドの調整パネル（G キー）で縦・横の大きさや線の濃さを変えられます。
       「グリッド → グリッドを元に戻す」で最初の見た目に戻ります。


================================================================
 24. 上級者向け（起動オプション）
================================================================

  python singing_trainer.py [曲のファイル] [オプション]

    --skip 秒           スキップ間隔の初期値（既定 5）
    --device 番号       マイクの番号を直接指定（python test_mic_pitch.py --list で確認）
    --out-device 番号   自分の声を出す機器の番号を直接指定
    --threshold dB      この音量より小さい音は声として扱わない（既定 -45）
    --latency 秒        自分の声のバーの表示位置の遅れ補正（既定 0.10）
    --fullscreen        全画面で起動
    --cpu               グラボを使わず CPU で解析
    --sep-model 名前    分離モデル htdemucs_ft（高精度・既定）/ htdemucs（速い）
    --engine 名前       音程の解析方法 auto / crepe / pyin / yin
    --crepe-model 名前  full（既定）/ tiny（速い）
    --midi-track 番号   MIDI のパートを手動で指定（例 2:0）
    --midi-offset 秒    MIDI のタイミングを手動で指定
    --font ファイル     日本語フォントを指定

  ※ 普段はオプションなしで起動すれば大丈夫です。
  ※ 機器はメニューの「デバイス」で選ぶ方が簡単です（番号は抜き差しで変わります）。

 25. アップデート（新しい版にする）
================================================================

  新しい機能や修正は、GitHub（shellbe1967/pitch-luna）に新しい版として置かれます。
  ソフトの中から、変わったファイルだけをダウンロードして入れ替えられます。

  ■ アップデートのしかた
    1) 「ヘルプ → アップデートを確認…」
    2) 新しい版があれば、版番号と変更点が表示されます → 「今すぐ更新」
    3) ダウンロードが終わったら「再起動して更新」
       → ソフトがいったん閉じ、黒い画面でファイルを入れ替えてから、自動で起動し直します。

  ■ お知らせ
    ・起動したときに裏で新しい版があるか確かめ、あれば画面にお知らせが出ます。
      「ヘルプ → 起動時にアップデートを確認する」で ON / OFF できます。
    ・今の版は「ヘルプ → バージョン情報」で確認できます（最近の変更点も表示）。

  ■ 安心のしくみ
    ・設定（settings.json）・解析した曲（cache）・テイク・お手本の編集版は変わりません。
    ・入れ替える前のファイルは backup フォルダに残します（最近の5回分）。
    ・ダウンロードしたファイルは確認用の値で確かめ、壊れていたら使いません。
    ・入れ替えの途中で失敗したときは、自動で元に戻します。
    ・新しく必要になったライブラリがあれば、自動でインストールします。
    ・記録は update_log.txt に残ります。

  ■ インターネットを使わないアップデート
    更新用の ZIP ファイルを受け取ったときは、「ヘルプ → ファイル (ZIP) からアップデート…」で
    その ZIP を選びます。あとは同じように「再起動して更新」で入れ替わります。

  ■ ビルド版（PitchLuna.exe）のアップデート
    ・ふだんのアップデートは、上と同じく「ヘルプ → アップデートを確認」で入れ替わります。
    ・ソフトの中の部品（ライブラリ）まで新しくなる版のときは、その旨が表示されます。
      その場合は、GitHub から新しい ZIP をダウンロードし、今のフォルダに上書きで展開してください。
      settings.json・cache・backup などのデータはそのまま残ります。

  ■ うまくいかないとき
    ・ビルド版で起動できないときは、フォルダの pitchluna_log.txt に記録が残ります。
    ・PitchLuna.exe --selftest を実行すると、部品の読み込みと短い曲の解析を試します
      （結果は selftest_result.json）。
    コマンドプロンプトで、ソフトのフォルダから次のように実行することもできます（Python で動かす場合）。
      python updater.py --check            新しい版があるか調べる
      python updater.py --update           ダウンロードして入れ替える（ソフトを閉じてから）
    前の版に戻したいときは、backup フォルダの中のファイルを、ソフトのフォルダに上書きしてください。

 26. 歌詞の表示（カラオケのように色が変わる）
================================================================

  楽譜（お手本バー）のすぐ下に「歌詞の段」を出します。
  文字はその音のお手本バーの真下に並んで一緒に流れ、歌うところまで
  カラオケのように左から色が変わります。

  ■ 歌詞を入れる
    1. 曲を開いてから、メニューの「歌詞 → 歌詞を入力・貼り付け…」を選びます。
    2. 歌詞カードなどを見ながら入力するか、コピーして貼り付けて「OK」を押します。
       ・1行ずつ改行で区切ってください（空の行は無視します）。
    3. 漢字の読み（ふりがな）を自動で調べ、1音ずつお手本バーに割り当てます。
       ・初めて使うときだけ、読みを調べる部品の準備に 30秒〜1分ほどかかります。
    ・歌詞は曲ごとに保存され、次に開いたときにも表示されます。
    ・歌詞は著作権のある文章です。ご自身で入力したものを、個人の練習の範囲でお使いください。
      このソフトがインターネットから歌詞を取ってくることはありません。

  ■ タイミングを合わせる（ずれていたら）
    自動の割り当ては、お手本バーの分かれ方によって、ところどころずれることがあります。
    ・行の歌い出しを記録する（おすすめ）
        「歌詞 → 行の歌い出しを記録する」を選び、Space で再生して、
        各行の歌い出しで Enter を押します。全部の行を押し終わると、
        それを手がかりに 1音ずつ割り当て直します。
        Backspace：1行戻す（3秒前に戻ります）　Esc：そこで終わる
    ・文字をドラッグ … その音のタイミングを左右に直します。
        Shift を押しながらドラッグすると、その行の後ろの文字も一緒に動きます。
    ・右クリックのメニュー
        ここから行の終わりまでを 1つ前 / 後ろのバーへ … 1音ずつずれているときに
        この行の歌い出しを、今の再生位置に
        この行だけ自動で割り当て直す / 歌詞全体を自動で割り当て直す
    ・Ctrl+Z / Ctrl+Y で元に戻す / やり直すができます。

  ■ ふりがな・歌詞を直す
    ・文字をダブルクリック（または右クリック →「ふりがなを直す」）で読みを入力し直せます。
      音の数が変わったときは、その行だけ割り当て直します。
    ・右クリック →「この行の歌詞を直す」で、1行だけ書き直せます。

  ■ 時間つき歌詞（.lrc）
    ・「歌詞 → 時間つき歌詞 (.lrc) を読み込む…」で、[00:12.34]歌詞 の形のファイルを読み込めます。
      行の歌い出しの時刻を手がかりに割り当てます。
    ・「歌詞 → .lrc ファイルとして保存…」で、記録したタイミングを .lrc として保存できます。

  ■ 表示の設定（メニューの「歌詞」）
    ・歌詞を表示（K キー） … 歌詞の段の表示 / 非表示
    ・ふりがなを表示 … 漢字の上に小さく読みを出す
    ・音程が合ったかで色を変える … 歌ったところを、合っていたら水色・ずれていたらオレンジに
    ・文字の大きさ … 小 / 中 / 大

  ※ 読み（ふりがな）を調べる部品として Janome（Apache License 2.0、辞書は mecab-ipadic）を
     使っています。くわしくは vendor フォルダの README.txt をご覧ください。
