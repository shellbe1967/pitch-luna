## Pitch Luna — If Vocal 1.1.0（Windows 用）

好きな曲を読み込むと、AI がボーカルを分けて「お手本の音程バー」を作ります。歌うと自分の声が線で重なり、音程のズレがひと目でわかる歌の練習ソフトです。

> **現在、期間限定で無料公開しています。** 今後の版は有料になる場合があります。

### ダウンロード

下の「Assets」から、**ZIP ファイルを 2 つともダウンロード**してください（合計 約 3GB）。

- `PitchLuna-1.1.0-part1of2.zip`
- `PitchLuna-1.1.0-part2of2.zip`

GitHub は 1 ファイル 2GB までのため、2 つに分けています。どちらか 1 つだけでは起動しません。

### 展開のしかた

1. `part1of2.zip` を右クリック →「すべて展開」
2. 展開先の欄の最後にある `\PitchLuna-1.1.0-part1of2` の部分を消す（例：`C:\Users\(あなたの名前)\Downloads`）→「展開」
3. `part2of2.zip` も同じように、**同じ展開先**に展開する
4. できた `PitchLuna-1.1.0` フォルダの中の `PitchLuna.exe` をダブルクリック

初めて起動したとき「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押してください（個人で作ったソフトのため署名がありません）。

### 動作環境

- Windows 10 / 11（64 ビット）
- マイク（ヘッドホン推奨）
- NVIDIA のグラフィックボードがあると曲の解析が速くなります（無くても動きます）
